# Quiz sobre natureza
Esse código é feito para ser um quiz personalizado sobre a natureza.
Nossa equipe utilizou recursos como HTML, JS e CSS para fazer um quiz divertido e interativo.
O objetivo principal desse quiz é ser apresentado em uma feira escolar.
